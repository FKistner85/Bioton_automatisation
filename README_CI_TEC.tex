\section*{Recording time: source and German clock}

The original Dawn Chorus column is named \textbf{localtimes} (the supplied local time). \textbf{Only when this field is absent, empty or whitespace-only} is the original \textbf{datetime} value used as a UTC instant and converted to \textbf{Europe/Berlin}. German winter time is UTC+1 and summer time is UTC+2; the conversion uses the timezone rules for the recording date, including date changes at midnight. Do not add a fixed offset or convert the resulting German clock a second time.\par

Examples without localtimes: 2025-01-15T06:00:00Z becomes 2025-01-15 07:00:00; 2025-07-15T06:00:00Z becomes 2025-07-15 08:00:00. A UTC evening can become the following German calendar day.\par

When localtimes is supplied, its local clock retains priority and is interpreted as German time. These recordings are unchanged by the fallback rule. A nonempty but invalid or unresolved localtimes value is flagged; it is not silently replaced with datetime. Source conflicts remain visible in the Step-1 time log.\par

\textbf{Audit on 28.09.2026:} all 3,288 recordings without localtimes already match this UTC-to-Germany conversion in both published master copies, including UTC, German date and clock, and the source label. No timestamp correction was required. Of these, 3,264 use UTC+2 and 24 use UTC+1. The published master has 108,578 recordings with source localtimes and 3,288 with source datetime.\par

\section*{Clean-data filters from the 9 October PDF}

Apply the filters needed by your analysis:\par

\begin{verbatim}
time_has_issues=False
sound_exists=True
duration_seconds >= 40
sound_has_issues=False
weather_point_exists=True
weather_point_has_issues=False
sentinel_exists=True
sentinel_has_issues=False
\end{verbatim}

The 40-second threshold is an analysis choice and can be replaced. Domain flags\par

do not automatically invalidate the entire recording. For training in cells with\par

a majority formation add grid\_100m\_has\_majority\_formation=True; for direct\par

point-in-LRT training add inside\_lrt\_polygon=True. Grid IDs alone certify neither.\par

\section*{Recording-time confidence and weather use}

\textbf{Use weather data only for recordings with} time\_has\_issues=False, equivalently timestamp\_source == "localtimes". UTC fallback timestamps are converted correctly but can differ from the actual supplied recording clock by up to two hours according to the PDF; conversion alone does not establish confidence in the source.\par

This source restriction supplements weather availability and quality checks. In schema v7, combined readiness flags include it. It does not automatically exclude the recording from audio-only work, and the audio-only bioacoustic readiness flag remains independent of time confidence. Recordings and stored files remain in the shared master.\par

\section*{Availability and issues}

\textbf{\_exists}: True means the corresponding files were recorded as present on LSDF. These flags describe the recorded inventory, not a live file check.\par

\textbf{\_has\_issues}: True means a problem or missing required data/check results. It can be True whether \_exists is True or False.\par

Empty means no check result is available.\par

\textbf{\_issue\_codes} gives the reason. Multiple codes are separated by a pipe; details may follow a colon. \textbf{\_has\_issues is not a severity level or a universal exclusion rule.} Rules below concern the affected file/domain, not automatically the entire recording. Unknown codes or a True issue flag without codes require review.\par

\section*{Point weather codes and suggested use}

Expected window: ten preceding complete German calendar days plus the recording day, hourly. Normally 264 rows; across spring DST 263, across autumn DST 265. The repeated local autumn hour is valid; a timezone-free timestamp alone cannot distinguish its two UTC instants.\par

\section*{Processing completion is separate from quality}

\textbf{is\_final does not currently exist.} ready\_for\_general\_analysis is not a ci-tec release flag: it requires trusted time provenance plus unflagged sound, weather and Sentinel together. It does not enforce an analysis-specific audio duration threshold; apply duration\_seconds \textgreater{}= 40 separately for the PDF clean filter.\par

Completion requires finished processing and checks for the required products, a specified input/code version and no outstanding repairs. Missing data and suitability remain separate. A permanent release applies only to a frozen version; later versions can reveal new errors. The shared master retains all rows.\par
